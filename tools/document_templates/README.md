# Retained document references

These are unchanged copies of the two supplied drafts, retained only as layout
and style references for `tools/build_manuals.py`. They are not the final manuals.
The final Greek text is in `Documentation`, and the final editable outputs are in
`output/documents`. Names and student IDs are intentionally omitted from the final
edition following the user's direction.

The builder preserves the reference page geometry and styles, translates and
completes the content, replaces the screenshot positions with actual runtime
captures, and corrects the original table width overflow. No reference file is
modified by the build.
