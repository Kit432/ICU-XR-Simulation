# Προσομοίωση ΜΕΘ και ψηφιακή τεκμηρίωση

Εκπαιδευτική εφαρμογή 3D για το μάθημα Αλληλεπίδραση Ανθρώπου Υπολογιστή. Ο χρήστης περιηγείται στον θάλαμο, ακολουθεί σενάρια JSON και αποθηκεύει τεκμηρίωση στον ηλεκτρονικό φάκελο ασθενούς. Τα ζωτικά σημεία είναι μεταβλητές προσομοίωσης.

## Εκτέλεση

Στον φάκελο `output/ICU_Submission/Application` εκτελέστε το `ICU-XR-Simulation.exe`. Διατηρήστε μαζί όλα τα αρχεία και τον φάκελο `ICU-XR-Simulation_Data`. Η εφαρμογή προορίζεται για Windows 64 bit.

1. Επιλέξτε σενάριο στο μενού **Scenarios** και πατήστε **Load selected**.
2. Πατήστε **Start training**. Το Load προετοιμάζει τα δεδομένα, ενώ το Start αρχίζει νέα εκτέλεση.
3. Χρησιμοποιήστε W A S D, ποντίκι και E στα ενεργά σημεία. Enter ή C συνεχίζει ένα μήνυμα.
4. Πατήστε F1 για βοήθεια, F2 για το μενού και Escape για κλείσιμο του ενεργού παραθύρου.
5. Στο EHR πατήστε **Save / Submit** σε κάθε απαιτούμενη φόρμα. Η πληκτρολόγηση μόνη της δεν αποθηκεύει.
6. Στο τέλος ελέγξτε τον απολογισμό και εξαγάγετε το αρχείο JSON πριν κάνετε reset.

Το μενού και η βοήθεια παγώνουν τον χρόνο της άσκησης. Τα κλινικά παράθυρα, συμπεριλαμβανομένου του EHR, αφήνουν τον χρόνο να συνεχίζεται. Το άνοιγμα ενός παραθύρου απενεργοποιεί την κίνηση και ελευθερώνει τον δείκτη.

## Άνοιγμα του πηγαίου κώδικα

Χρησιμοποιήστε **Unity 6000.4.8f1** με υποστήριξη Windows Build. Ανοίξτε τον φάκελο του έργου στο Unity Hub και τη σκηνή `Assets/Scenes/ICUTraining.unity`. Αυτή είναι η τελική σκηνή και η μοναδική σκηνή του build. Η `SampleScene` περιέχει επίσης την τελική διάταξη για συμβατότητα με παλαιότερες συντομεύσεις του έργου.

Οι φάκελοι `Assets`, `Packages` και `ProjectSettings` αποτελούν το αναπαραγώγιμο έργο. Το Unity αναδημιουργεί το `Library` κατά την εισαγωγή. Οι εκδόσεις πακέτων καταγράφονται στα `Packages/manifest.json` και `Packages/packages-lock.json`.

## Επεξεργασία της εμφάνισης

Η εμφάνιση αποθηκεύεται σε κανονικά Unity GameObjects, Canvas, prefabs, υλικά και εισαγόμενα μοντέλα. Τα αρχεία `Assets/Prefabs/UI` και `Assets/Prefabs/CallButton.prefab` είναι επεξεργάσιμα στον Inspector. Δεν απαιτείται αλλαγή κώδικα για αλλαγή χρωμάτων, γραμματοσειρών ή γεωμετρίας των παραθύρων.

Το EHR χρησιμοποιεί επεξεργάσιμα πρότυπα καρτέλας, φόρμας και γραμμής πεδίου μέσα στο `EhrPanel`. Η λογική δημιουργεί αντίγραφα αυτών των έτοιμων προτύπων για τα δεδομένα κάθε JSON. Οι διαστάσεις, τα χρώματα και η διάταξη ανήκουν στα assets. Οι κυματομορφές και οι ενδείξεις αλλάζουν δυναμικά με βάση την κατάσταση της προσομοίωσης.

## Σενάρια και εξαγωγές

- `icu_scenario_hypoxia_v1.json`: το αρχικό σενάριο με 8 κόμβους, 3 αποφάσεις, 2 πύλες τεκμηρίωσης, όριο 30 δευτερολέπτων και καθολικό συναγερμό.
- `icu_scenario_reassessment_v2.json`: παραλλαγή εξάσκησης με όριο 45 δευτερολέπτων και μήνυμα επανεκτίμησης που παραπέμπει στις τρέχουσες τιμές.

Για νέο σενάριο προσθέστε JSON στο `Assets/StreamingAssets/Scenarios` ή, στο εκτελέσιμο, στο `ICU-XR-Simulation_Data/StreamingAssets/Scenarios`, και ανανεώστε τη λίστα. Χρησιμοποιήστε τα πέντε υπάρχοντα αναγνωριστικά ενεργών σημείων για τον παρόντα θάλαμο. Τα σφάλματα ανάγνωσης και δομής παρουσιάζονται στο μενού.

Οι εξαγωγές αποθηκεύονται στον φάκελο `SessionLogs` της διαδρομής `Application.persistentDataPath`. Στα Windows η συνήθης διαδρομή είναι `%USERPROFILE%/AppData/LocalLow/ICUSimulation/ICU XR Simulation/SessionLogs`. Η εφαρμογή εμφανίζει την ακριβή διαδρομή μετά την εξαγωγή. Το σκορ εκφράζει ακατέργαστους βαθμούς του σεναρίου και μπορεί να ξεπερνά το 100.

Το αρχικό κείμενο του κόμβου `n5_reassessment` αναφέρει SpO2 94% ακόμη και μετά την επιλογή αναμονής που ορίζει 80%. Το αρχικό JSON διατηρείται αμετάβλητο. Για την πραγματική κατάσταση της εκτέλεσης χρησιμοποιήστε τις τρέχουσες τιμές Monitor/EHR. Η δεύτερη παραλλαγή αποφεύγει αυτή τη λεκτική ασυνέπεια.

## Έλεγχοι και build

Οι αυτοματοποιημένοι έλεγχοι EditMode βρίσκονται στο `Assets/Tests/EditMode` και εκτελούνται από το Unity Test Runner. Το μενού **ICU → Build Windows Release** παράγει το πλήρες εκτελέσιμο. Το `ReleaseBuild` εκτελεί build της αποθηκευμένης σκηνής και δεν παράγει μοντέλα ή διάταξη UI.

Το `Assets/Tests/Acceptance/ReleaseAcceptance.cs` είναι προαιρετικός έλεγχος του κανονικού εκτελέσιμου. Ενεργοποιείται μόνο με το όρισμα `--acceptance-output` και μια απόλυτη διαδρομή αποτελεσμάτων. Συμπληρώνει τα πραγματικά πεδία και καλεί τα κουμπιά αποθήκευσης, χωρίς παράκαμψη πύλης. Καταγράφει JSON αποτελεσμάτων και πραγματικά στιγμιότυπα της εφαρμογής. Δεν είναι μελέτη χρηστών ούτε μέτρηση κλινικής απόδοσης.

Δείτε το `Evidence/verification-summary.md` για τα πραγματικά αποτελέσματα και τα όρια της επαλήθευσης. Τα ελληνικά εγχειρίδια περιλαμβάνονται στο `output/documents` και στο τελικό πακέτο.

## Παράδοση

Το `output/ICU_Submission` περιλαμβάνει εφαρμογή, στιγμιότυπο πηγαίου κώδικα, JSON σενάρια, ελληνικά εγχειρίδια και τεκμήρια ελέγχων. Τα ονόματα και οι αριθμοί μητρώου παραλείπονται κατόπιν αιτήματος και μπορούν να προστεθούν πριν την υποβολή. Η κατανομή πραγματικών συνεισφορών και η επιβεβαίωση αδειών των προϋπαρχόντων εξωτερικών assets παραμένουν ευθύνη της ομάδας.
